# Status

## Current source

The development source targets .NET 11 with SDK-matched Roslyn and C# 15.
Published package versions are identified by stable Git tags; source checks,
package checks and installed-client acceptance are separate boundaries.
See [verification](VERIFICATION.md) and the [release checklist](RELEASE.md).

Shared transport rollout: shared mode is the recommended configuration;
private stdio remains the rollback path.

Argument compatibility is selected with `LIFEBLOOD_JSON_COMPAT=legacy|warn|strict`.
`LIFEBLOOD_STRICT_JSON` remains a compatibility input. Telemetry uses
`lifeblood.tool.arguments` and `lifeblood.analyze.phase`.

Runtime Async is disabled in production. Host compiler support does not change
the language version, references or defines of an analyzed project. Host emit
is not a Unity, Player or native compiler build.

Consumer captures, process inventories and deployment journals are not public
verification artifacts. Reproduce product checks using synthetic fixtures or
public inputs rather than publishing private workspace output.

## Known Limitations

Dead-code findings remain advisory when reflection, unresolved assets or
unrecognized callback conventions can hide live references.

**Call-graph completeness.** Eight extractor gaps closed across v0.6.4 + v0.6.5 raised edge count substantially. `find_references`, `dependants`, `blast_radius`, and `file_impact` all benefit.

**Truth envelope.** Every read-side response ships an `envelope` field with truth tier / confidence / staleness / limitations. Errors deliberately do NOT carry envelopes. Per-tool classification lives on `ToolDefinition.EnvelopeClassification` in the registry (`INV-ENVELOPE-001`).
