Lifeblood architecture

Roslyn truth in. Shared agent context out.

Lifeblood analyzes C# and Unity workspaces with Roslyn, commits one immutable semantic publication, and exposes compiler backed queries to every connected agent. Hexagonal boundaries keep the core independent from Roslyn, Unity, Git, runtime captures, transports, and client applications.
